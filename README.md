# COMPSCI 3VA3 — Information Visualization

Course website for COMPSCI 3VA3, Information Visualization, at McMaster University.

**Instructor:** Swati Mishra
**Term:** Fall 2026

## About

A static site built with plain HTML/CSS covering the course overview, schedule, tutorials, assessments, and teaching staff.

## Structure

- `index.html` — main page
- `style.css` — styling
- `images/` — logo and figures used on the page

## Viewing locally

Open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:

```
python3 -m http.server
```

## Deployment

Hosted via GitHub Pages from this repository.
